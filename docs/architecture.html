Azure AI Studio Hub & Projects Module

Azure AI Studio

Executive Summary

Production-ready Terraform module for deploying Azure AI Studio with hub workspaces, child projects, compute instances, model deployments (via Cognitive Services), workspace connections, and private endpoints. The hub workspace acts as the central governance layer backed by Storage Account, Key Vault, Application Insights, and Container Registry. Projects inherit hub resources and provide isolated workspaces for teams. Supports customer-managed key encryption, multiple identity types, and full network isolation.

Data Flow

1
Data scientists access AI Studio portal via the Hub workspace.
2
Projects provide isolated workspaces for different teams/use cases.
3
Compute instances provide managed VMs for model development.
4
Model deployments expose LLMs via Cognitive Services for inference.
5
Backing services (Storage, Key Vault, ACR) store data, secrets, and container images.
6
Private endpoints ensure all traffic flows within the VNet.

Production Readiness Checklist

  • Configure private endpoints for hub workspace
  • Use UserAssigned identity for cross-service access
  • Enable CMK encryption for sensitive workloads
  • Disable public network access in production
  • Assign compute instances to specific users
  • Set RAI policies on model deployments
  • Connect Application Insights for monitoring
  • Configure Container Registry for custom model images
  • Set appropriate SKU (Standard/Premium for production)
  • Create separate projects per team for isolation
